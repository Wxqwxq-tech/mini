# 拿来说明 · C1 课程资料获取与翻译

> 这份材料「拿去就能看懂、拿去就能复现」。下面说明：材料从哪来、怎么处理、产物在哪、怎么验证、以及哪些还没覆盖。

---

## 一、材料来源

- **主材料**：`CS146S_offline.zip`（课程站点离线包，52 个条目，含 `pages/`、`pdfs/`、`assets/`、`slides_info/`、`site/`）。
- **附带 PDF**：`Vibe_Coding_Playbook.pdf`（7.96 MB，扫描件）。

解压后目录：`材料_解压/`。

## 二、怎么把它变成中文（复现步骤）

在 `C1工作区/` 下依次执行：

```bash
# 1) 抽取：zip 内 HTML/PDF → 纯文本（source/pages、source/pdfs）
python pipeline/01_extract.py

# 2) 分段：按 2600 词切分为 60 个单元（work/units.json）
python pipeline/02_segment.py

# 3) 翻译：读 pipeline/术语表.md，分批把 work/ 单元译成中文，
#    落盘到 translated/_parts/<单元名>.md

# 4) 装配：合并 part → 成品文章（translated/pages、translated/pdfs）
python pipeline/03_assemble.py

# 5) 抽检：查缺译 / 英文残留 / 术语命中率
python pipeline/04_spotcheck.py
```

## 四、怎么验证质量

1. `04_spotcheck.py` 输出「文件总数 / 缺译 / 高英文残留 / 术语命中」四类指标。
2. 术语命中：智能体 652、上下文 324、代码评审 178、漏洞 145、提示注入 57……说明核心术语统一。
3. 两处 HIGH-EN（code-reviews-just-do-it、owasp-top-ten）已人工核对，英文残留均为**站点头部导航、译者人名、无关文章摘要、法律声明**，正文已全译，非漏译。
