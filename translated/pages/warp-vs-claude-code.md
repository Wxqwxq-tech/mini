# Warp 与 Oz 入门指南

开始使用 Warp——智能体式开发环境（Agentic Development Environment），以及 Oz——面向云智能体的编排平台。

Warp 是一个智能体式开发环境（Agentic Development Environment），它将现代终端与强大的智能体相结合，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz——面向云智能体的编排平台——提供支持。

[图: Warp——智能体式开发环境：Warp Terminal（专为与智能体一起编码而打造的现代终端）和 Oz（面向云智能体的编排平台）]
Warp 将现代终端与 Oz（面向云智能体的编排平台）相结合

## 
hashtag

Warp

Warp 是你工作的地方——一个快速、现代的终端，专为与智能体一起编码而打造。

核心能力：

- 

智能体模态（Agent Modality）arrow-up-right：在用于命令的简洁终端和用于多轮智能体工作流的专用对话视图之间切换。

- 

现代终端体验：光标移动、基于块的导航、多行编辑、语法高亮和丰富的补全。使用 Rust 构建以获得高性能。

- 

代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。

- 

编码智能体集成arrow-up-right：语音输入等功能，以及用于处理基于终端图像的 @-选择。与 Oz 或 Claude Code、Codex 等智能体兼容。

深入了解 Warp 的核心功能
## 
hashtag

Oz：面向云智能体的编排平台

Oz 是面向云智能体的编排平台，为 Warp 的所有智能功能提供支撑。Oz 旨在规模化地协调智能体——理解你的代码库、自主执行任务并适应你的工作流。Oz 在设计上支持多模型，让你能够灵活地为每项任务选择最佳的大语言模型（LLM）。

Oz 以两种模式运行：

### 
hashtag

本地智能体

直接在 Warp 应用中运行，提供实时、交互式的编码协助。

- 

在整个代码库中编写和重构代码

- 

调试问题并修复错误

- 

运行命令并解读结果

- 

规划并执行多步骤任务

本地智能体让你始终掌控局面。你可以审查更改、在任务进行中引导智能体，并在操作执行前进行批准。

→ 开始使用本地智能体arrow-up-right

### 
hashtag

云智能体

Oz 云智能体在 Warp 的基础设施（或你自己的基础设施）上于后台运行，以实现规模化自动化。

- 

触发器：对来自 Slack、Linear、GitHub 或自定义 Webhook 的事件做出响应

- 

定时任务：运行依赖更新或死代码清理等周期性任务

- 

并行性：跨仓库或任务并发运行多个智能体

- 

可观测性：每次运行都被追踪、可审计，并可与你的团队共享

云智能体非常适合无需你即时关注的工作，例如拉取请求（PR）评审、Issue 分诊、例行维护以及集成驱动的工作流。

→ 了解云智能体arrow-up-right

## 
hashtag

它们如何协同工作

Warp 和 Oz 在本地与云开发之间提供统一的体验：

- 

同一个智能体，随处可用：无论你是在 Warp 中交互式地工作，还是在云端运行智能体，你使用的都是相同的底层智能体能力。

- 

无缝交接：在云端启动任务，当你想亲自掌控时，在 Warp 中于本地接管，而不会丢失进度或上下文。

- 

共享上下文：Warp Drive、Rulesarrow-up-right 和 MCP 服务器arrow-up-right 可同时作用于本地和云智能体，因此你的团队的知识和工具始终可用。

- 

团队协作：共享智能体会话、审查智能体的操作，并引导正在运行的任务，无论这些任务由谁发起。

## 
hashtag

多模型支持

Oz 在设计上支持多模型。你可以从一组精选的顶级模型中选择你偏好的大语言模型（LLM）arrow-up-right。

## 
hashtag

隐私与安全

Warp 符合 SOC 2 标准，并与所有签约的大语言模型（LLM）提供商签订了零数据留存（Zero Data Retention）政策。任何客户 AI 数据都不会被保留、存储或用于训练。

Warp 的 AI 功能可以在「设置 > AI」中全局禁用。

→ 进一步了解数据隐私arrow-up-right
